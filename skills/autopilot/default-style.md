# Demo style notes

Taste, not rules. Weigh these against what each part of the video shows. Autopilot adds to this file when you
correct it or state a preference; edit it any time.

## Pacing
- Agent runs: the time an agent spends working on its own is waiting time. Fast-forward it to about 3-6 seconds,
  however long the run was, and keep the moment the result appears.
- Typing to the agent: keep it readable. About 1.5-2x, never faster.
- Reading output: slow scrolling or pausing on results is usually where the narration goes. Keep it near real time.
- Navigation between apps or pages: about 2 seconds.
- Keep any one section of UI to about 10 seconds or less.
- Show results once. One clear walkthrough beats several similar ones.
- Cut loading screens, logins, and anything private (keys, emails, customer data).

## Narration
- The narration text is the exact script. Read it word for word.
- Retime the footage to the voice rather than squeezing the voice into the footage.
- Use the real narration voice even for drafts; timing depends on it. Ask before spending credits.
- A short pause after the opening line helps the intro land.

## Ending
- Last shot, fade to black, then the sign-off line over black.
